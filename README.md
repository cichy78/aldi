# ALDI VST · Wilsdruff

PWA do wyszukiwania sklepów VST, nawigacji, mapy i Dispo.

**Autor: Cichocki Tomasz**

## Funkcje

- Ekran startowy ALDI + animacja + Start
- **Ikona APK „ALDI VST”** (niebiesko-pomarańczowa)
- Język **PL / DE**
- Szukanie VST / miasto / ulica, filtry
- Nawigacja Google Maps, mapa (kafelki offline po 1. wyświetleniu)
- Ulubione, historia
- **Dispo** + pływający przycisk 📞
- **PIN** (opcjonalny, 4–8 cyfr)
- **10 motywów** + **Auto (system)**
- Import/Export JSON, CSV, XLSX, **PDF** (wszystkie / ulubione / miasto)
- Alert przy zmianie Zeitbeschränkung po imporcie
- PWA / GitHub Pages / APK (PWA Builder)

## GitHub Pages → APK

1. Wrzuć pliki do repo
2. Pages → branch `main`
3. [pwabuilder.com](https://www.pwabuilder.com) → URL → Android package  
   Ikona: `icon-512.png` (ALDI VST)
