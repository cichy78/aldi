## Ważne przy APK / GitHub Pages

1. Wrzuć **całą zawartość** folderu na root repo (albo włącz Pages z folderu `/docs` – wtedy przenieś pliki do `docs/`).
2. URL musi być **HTTPS** (GitHub Pages daje to automatycznie).
3. Po zmianach: twarde odświeżenie / odinstaluj starą PWA i zainstaluj ponownie.
4. **PWA Builder**: wklej pełny URL do `index.html`, np.  
   `https://USER.github.io/REPO/index.html`
5. Jeśli repo nie jest `username.github.io`, aplikacja jest pod  
   `https://USER.github.io/NAZWA-REPO/` – nie pod samą domeną.
